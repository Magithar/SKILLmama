# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Report it privately through GitHub's **Report a vulnerability** flow for this
repository. Include the affected version, reproduction steps, impact, and any
available mitigation.

If private reporting is unavailable, contact the maintainer through the email
address listed on the maintainer's GitHub profile and include `[security]` in
the subject.

The npm package, CLI, plugin metadata, installer documentation, and
security-gate implementation are in scope.
